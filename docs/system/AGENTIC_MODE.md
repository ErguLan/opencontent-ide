# Agentic Mode (`useWorkspaceAI.js`)

## Overview

Agentic Mode transforms the AI from a **single-response generator** into a **multi-step task executor**. Instead of one prompt → one response, the AI plans a sequence of steps and executes them autonomously.

## Flow

```
User: "Create a post about coffee, then generate 3 images"
    ↓
Agentic Toggle = ON
    ↓
startGeneration({ prompt, agenticMode: true })
    ↓
executeAgenticPlan({ prompt, ... })
    ↓
Step 1: PLANNING
    sendToAI(prompt, plannerPrompt)              ← system prompt asks for JSON plan
        ↓
    AI returns: [
        { type: "text", description: "Write coffee post", prompt: "..." },
        { type: "image", description: "Coffee cup", prompt: "..." },
        { type: "image", description: "Coffee beans", prompt: "..." }
    ]
    ↓
Step 2: EXECUTION LOOP
    for each step:
        ↓
        Update agentSteps[i] → status: "working"
        ↓
        if step.type === "text":
            sendToAI(context, textModel, { stream: true })
            display result inline
            accumulate text

        if step.type === "image":
            generateImage(step.prompt, imageModel)
            saveMedia to gallery
            accumulate image references
        ↓
        Update agentSteps[i] → status: "completed" or "error"
    ↓
Step 3: FINALIZE
    Create version with accumulated text + images
    Set agentState → COMPLETE
    Save project
```

## Planner System Prompt

The planner instructs the AI to output a JSON array:

```
You are a task planner. Break the user's request into an array of steps.
Each step must have: type ('text', 'image', 'analyze'), description, and prompt.
Output ONLY valid JSON array, no other text.

Example:
[{"type":"text","description":"Write post about coffee","prompt":"Write an Instagram post about coffee..."},
 {"type":"image","description":"Generate coffee image","prompt":"A steaming cup of coffee..."}]
```

If the AI response cannot be parsed as JSON, the entire response is treated as a single text step.

## State Tracking

During agentic execution, `agentSteps` tracks each step:

```js
agentSteps = [
    { id: "step-0", text: "Writing coffee post...", status: "working" },
    { id: "step-1", text: "Generating coffee image...", status: "waiting" },
    { id: "step-2", text: "Generating coffee beans...", status: "waiting" }
]
```

Status transitions: `waiting → working → completed` (or `error`)

## Image Auto-Save

All generated images during agentic execution are automatically saved to the media library (IndexedDB) via `saveMedia()`:

```js
const blob = await (await fetch(imgResult.imageUrl)).blob();
await saveMedia(blob, `agentic-img-${Date.now()}.png`, {
    role: 'reference',
    tags: ['agentic', 'generated']
});
```

This makes them visible in the Gallery (`/gallery`).

## Usage Tracking

After execution, `onIncrementUsage` is called with:
```js
{
    generate: numberOfTextSteps,
    image: numberOfImageSteps
}
```

## Current Limitations

- Only supports `text` and `image` step types (no `analyze`/`edit` yet)
- Error in a step does not stop the pipeline (marks as error and continues)
- Image generation failure is silent (just skips that step)
- Plan is generated by AI — if AI outputs bad JSON, falls back to single text step
