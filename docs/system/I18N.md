# i18n System (`src/i18n/`)

## Architecture

Simple JSON-based translation system with `t()` function supporting dot notation and variable interpolation.

## File Structure

```
src/i18n/
├── index.js        # t(), setLanguage(), getLanguage(), getSection()
├── en.json         # English translations
└── es.json         # Spanish translations
```

## How It Works

### `t(key, vars?, lang?)`

```js
import { t, setLanguage } from '../../i18n';

setLanguage('en');
t('common.close');              // → "Close"
t('common.close', {}, 'es');    // → "Cerrar"
t('cli.themeSet', { theme: 'dark' });  // → "Theme set to dark"
t('nonexistent.key');           // → "nonexistent.key" (fallback)
```

- Uses dot notation to traverse nested JSON
- Interpolates `{varName}` patterns with `vars` object
- Falls back to `currentLanguage` if `lang` not specified
- Returns the key itself if translation is not found

### `setLanguage(lang)`

Sets the global language. Accepted values: `'en'`, `'es'`.

### `getLanguage()`

Returns the current language code.

### `getSection(section, lang?)`

Returns an entire section object:
```js
getSection('common')
// → { close: "Close", save: "Save", ... }
```

### `getLanguages()`

Returns available languages:
```js
[
    { code: 'es', name: 'Espanol', flag: 'ES' },
    { code: 'en', name: 'English', flag: 'EN' }
]
```

## JSON Structure

Keys are organized by feature/section:

```json
{
    "common": {
        "close": "Close",
        "save": "Save",
        "delete": "Delete"
    },
    "workspace": {
        "actions": {
            "save": "Save project",
            "export": "Export"
        },
        "media": {
            "title": "Templates & Assets",
            "upload": "Upload"
        }
    },
    "agentic": {
        "planning": "Planning tasks...",
        "plannerPrompt": "You are a task planner...",
        "complete": "Agentic pipeline complete"
    }
}
```

## Adding a New Language

1. Create `src/i18n/{code}.json` with the same structure as `en.json`
2. Add the language to `getLanguages()` in `index.js`
3. Add the language to `translations` object
4. Import the JSON file

## Using in React Components

```jsx
import { useLanguage } from '../../context/LanguageContext';

function MyComponent() {
    const { t, language, changeLanguage } = useLanguage();
    return (
        <div>
            <h1>{t('app.name')}</h1>
            <button onClick={() => changeLanguage('es')}>ES</button>
        </div>
    );
}
```

The `useLanguage()` context hook provides:
- `t(key, vars)` — translation function
- `language` — current language code
- `languages` — available languages array
- `changeLanguage(code)` — switch language
